# LuaPlayerYT-MCSM

### [english readme version / английская версия readme](./README.md)

## Особенности форка

1. **Простая настройка экрана ошибок** - Простые опции для настройки внешнего вида ошибок, звуков, шрифта и фонового изображения.
2. **Упрощённый процесс сборки** - Используется скрипт `build.sh`, который легко редактировать и добавлять необходимые команды компиляции.
3. **Минималистичный код** - Удалены ненужные библиотеки для уменьшения размера и упрощения поддержки.
4. **Оптимизации** - например: collect garbage в pmp_play, что делает pmp_play гораздо стабильнее
5. **Дополнительные комментарии в коде** - Добавлены поясняющие комментарии к настройкам для облегчения изменения.

**Примечание:** Этот форк создан специально для порта [Minecraft: Story Mode PSP](https://github.com/entitybtw/mcsm_portable), поэтому все оптимизации движка в первую очередь направлены на улучшение работы этого порта и обеспечение стабильной работы на PSP.

## Как собрать?

1. Установите PSPSDK согласно [инструкции](https://pspdev.github.io/installation.html).
2. Клонируйте репозиторий в нужную папку командой:

```bash
git clone https://github.com/entitybtw/LuaPlayerYT-MCSM
```

3. Откройте папку репозитория в терминале и запустите сборку:

```bash
./build.sh
```

## Как скачать последнюю версию без сборки?

В репозитории есть авто-билдер, который компилирует текущую версию из последнего кода.

Чтобы скачать:

1. Перейдите на вкладку **Actions** для основной ветки.
2. Выберите самую последнюю сборку (чем выше — тем новее).
3. В разделе **Artifacts** скачайте `EBOOT.PBP`.

**Примечание:** Эти сборки компилируются из последнего кода и могут быть нестабильными в некоторых ситуациях.
